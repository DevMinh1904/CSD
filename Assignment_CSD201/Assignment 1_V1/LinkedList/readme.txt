# Josephus Problem Solver

This is a Java program that solves the Josephus problem using a circular linked list.

## Prerequisites

You need to have Java Development Kit (JDK) installed on your machine to compile and run this program.
I using Netbean IDE to compile and run 
## How to Compile

1. Open a terminal window.
2. Navigate to the directory containing the `JosephusProblemSolver.java` file.
3. Run the following command to compile the Java file:

```bash
javac JosephusProblemSolver.java
